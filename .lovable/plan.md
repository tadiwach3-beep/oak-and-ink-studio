# Oak & Ink homepage redesign

## Goal
Rebuild the homepage as a professional founder-led digital studio using the supplied white, black, and burnt-orange editorial direction.

## Homepage
- Replace the current dark graphic-design positioning with the new digital-solutions message.
- Build the requested sequence: navigation, hero, trust strip, services, selected work, process, principles, founder story, call-to-action, contact, and footer.
- Use the existing project artwork as framed website mockups, clearly labelled as concept work.
- Keep navigation compact and add a functional mobile menu.
- Keep the working email enquiry delivery, expanding the form with business and service fields.
- Keep email, phone, WhatsApp, and general Western Cape location links; remove the home address and map.

## Visual system
- White-dominant editorial layout with black type, light-grey rules, and restrained burnt-orange accents.
- Space Grotesk headings with Inter body copy.
- Sharp typography, generous spacing, thin borders, minimal shadows, and small corner radii.
- Tailored mobile stacking, full-width touch-friendly actions, and reduced-motion support.

## Technical details
- Update global semantic color and typography tokens.
- Rebuild the homepage using existing shared buttons and form controls.
- Update page metadata to match the digital-solutions positioning.
- Preserve existing service routes but do not add case-study pages yet.
- Verify the build and inspect desktop and mobile layouts for overflow and overlaps.
